## 5. CDN 刷新

由于 CDN 缓存时间约 30 天，更新首页后必须刷新这些 URL：

- `https://camps.wanli.wiki/`
- `https://camps.wanli.wiki/index.html`
- `http://camps.wanli.wiki/`
- `http://camps.wanli.wiki/index.html`

刷新脚本从 `~/.cos.conf` 读取凭证，不输出 Secret：

```bash
课程产品包/07_Web教学系统/scripts/refresh_camps_cdn.py --poll
```

查询刷新状态时使用返回的 `TaskId`：

```bash
课程产品包/07_Web教学系统/scripts/refresh_camps_cdn.py --status TASK_ID
```
