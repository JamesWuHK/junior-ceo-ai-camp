# Day1 选方向，找想帮的人：12 个项目连环画

风格：baoyu-comic / chalk / warm / four-panel / 4:3。

用途：孩子可见课件页。每个项目一张四格连环画，先让孩子看见“没有产品时的小麻烦”，解决方案留给小组讨论。

共同要求：
- 温暖粉笔手绘连环画，2x2 四格，4:3 横版。
- 图中不要写长句，不要放英文、logo、水印。
- 每格只画一个主要动作，表情和场景要清楚。
- 文字字幕用 HTML 显示在图片下方，图片本身尽量少字。
- 不提前画现成产品，只把场景、需求和待解决的问题讲清楚。

## 孩子可见文案检查

- 10 岁能懂：通过。每个故事都从家庭、学校、作业、创作或课间小交换开始。
- 需求明确：通过。每个故事最后都留下一个具体问题。
- 不雷同：通过。12 个项目覆盖出门、喝水、花钱、拆题、错因、口语、写作、游戏、漫画、小课、交换、点单。
- 不抢孩子想法：通过。故事只讲问题，不把现成产品答案画出来。
- 内部词：无。
