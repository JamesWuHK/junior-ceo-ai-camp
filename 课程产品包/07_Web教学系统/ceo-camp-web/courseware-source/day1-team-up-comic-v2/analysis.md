# 校园活动组队板：连环画内容分析

## 目标

用一个孩子想参加无人机体验但找不到队友的故事，让孩子看见“有兴趣的人互相看不见”这个校园麻烦，再看到一个小产品怎样让想参加的人找到彼此。

## 受众

8-12 岁孩子。画面要让孩子有“我也遇到过”的感觉：活动想参加、需要组队、问人有点尴尬、差点错过同伴。

## 角色

- 航航：10 岁男孩，短黑发，蓝色外套，喜欢无人机，想参加活动但不敢一直问。
- 琪琪：10 岁女孩，齐肩黑发，紫色卫衣，也想参加无人机体验，但不知道谁缺队友。
- 同学若干：分别想去篮球、手工、还没决定，作为友好背景。

## 叙事节拍

1. 走廊公告板前，航航看到“无人机体验，三人一组”，眼睛亮了又皱眉。
2. 航航问了几位同学，大家选择不同活动，他有点尴尬。
3. 琪琪也想参加，却不知道谁还缺人，两个人差点错过。
4. 校园活动组队板出现活动卡：无人机体验、还缺 1 人、我也想加入。
5. 琪琪加入，三人组凑齐，还分好谁排队、谁记录、谁试飞。

## 画风

- 一页五格连环画，4:3 单格主画面。
- 温暖手绘 sketchnote / 粉笔感，校园走廊、公告板和活动卡清楚。
