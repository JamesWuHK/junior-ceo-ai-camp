Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“琪琪加入后，三人组凑齐，可以报名参加无人机体验”的开心结果。
Scene/backdrop: 学校走廊公告板前或活动报名桌旁，有无人机体验图标海报、报名小纸条和分工便签。
Subject: 航航，10 岁中国男孩，蓝色外套；琪琪，10 岁中国女孩，紫色卫衣；还有一位同学组成三人组。航航和琪琪轻轻碰拳，三个人开心但不夸张。桌上有三张分工小纸条，分别写着：排队、记录、试飞。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，温暖、真实、有行动感。
Composition/framing: 中景，三人组在画面中心，公告板和报名桌在后方，分工纸条在前景。
Lighting/mood: 明亮、轻松、有“可以开始了”的兴奋。
Color palette: 米白纸面、黑线、蓝色外套、紫色卫衣、黄色公告板、绿色小勾图标。
Visible text: 只允许出现这些短中文：排队、记录、试飞。不要出现其他文字。
Constraints: 画面要清楚表现“组齐了，可以报名了”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要比赛颁奖，不要成人会议，不要商业社交软件感。
