Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“孩子为了组队连续问同学，但大家想去不同活动，他有点尴尬”。
Scene/backdrop: 学校走廊或教室门口，公告板附近，同学们课间聊天。
Subject: 航航，10 岁中国男孩，蓝色外套，拿着报名小纸条，依次问三位同学。三位同学分别用动作或图标表达想去篮球、手工、还没决定；大家友好地回应，没有拒绝嘲笑。航航表情从期待变成有点尴尬。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，有轻微动线表示问了一圈。
Composition/framing: 横向中景，航航在中间，三位同学分布左右，地面上可有手绘虚线表示他走来走去。
Lighting/mood: 温暖真实，有一点“再问会不会打扰别人”的小尴尬。
Color palette: 米白纸面、黑线、蓝色外套、篮球橙色、手工彩纸多色。
Text: 不要在图片里写任何字，不要气泡文字，全部用动作和图标表达。
Constraints: 画面要表达“找同伴很费劲，而且有点不好意思”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要画成被排挤，不要同学冷漠，不要校园霸凌，不要消极管控语气。
