Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“孩子在学校走廊看到无人机体验活动，需要三人一组，想参加但缺队友”的瞬间。
Scene/backdrop: 学校走廊公告板前，午休或课间，公告板上贴着几张活动海报，用图标表示篮球、手工、无人机，不要可读文字。
Subject: 航航，10 岁中国男孩，短黑发，蓝色外套，背着小书包，站在公告板前看见无人机体验海报，眼睛发亮，但又皱眉，因为海报上写着三人一组。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，温暖校园感，不要照片感，不要 3D。
Composition/framing: 中景，公告板占左侧，航航在右侧，海报上的无人机图标和三人组图标清楚。
Lighting/mood: 明亮课间光，有期待也有一点为难。
Color palette: 米白纸面、黑线、蓝色外套、黄色公告板、绿色和橙色活动图标。
Visible text: 海报上只允许出现这些短中文：无人机体验、三人一组。不要出现其他文字。
Constraints: 画面要让孩子看懂“想参加活动，可还差队友”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要真实学校名，不要品牌无人机 logo，不要成人活动海报感。
