Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“另一个也想参加活动的孩子站在公告板另一边，但不知道谁缺队友，两个人差点错过”。
Scene/backdrop: 学校走廊公告板前，公告板中间贴着无人机活动图标海报，不要可读文字。
Subject: 琪琪，10 岁中国女孩，齐肩黑发，紫色卫衣，站在公告板另一侧看着无人机海报，表情犹豫；远处航航低头准备离开。两个人之间有公告板或人群隔开，表现“互相看不见”。琪琪手里拿着书，像想加入但不知道找谁。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，情绪清楚。
Composition/framing: 宽中景，琪琪在前景一侧，航航在背景另一侧，中间公告板形成视觉分隔。
Lighting/mood: 温暖但有一点“差点错过”的遗憾。
Color palette: 米白纸面、黑线、紫色卫衣、蓝色外套、黄色公告板、淡蓝无人机图标。
Text: 不要在图片里写任何字，不要气泡文字。
Constraints: 画面要让孩子看懂“其实有人也想去，只是彼此不知道”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要悲伤夸张，不要成人社交软件感，不要真实学校名。
