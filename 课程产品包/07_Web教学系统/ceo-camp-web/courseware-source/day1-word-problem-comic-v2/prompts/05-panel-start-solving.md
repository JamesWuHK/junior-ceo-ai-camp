Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“应用题被拆清楚以后，孩子开始自己写算式”的变化。
Scene/backdrop: 数学教室课桌，桌上有拆题板屏幕、练习纸和草稿纸。
Subject: 小宇，10 岁中国男孩，短黑发，绿色校服外套，表情放松，正在草稿纸上写自己的第一步算式。屏幕旁边仍能看到四张卡，其中“第一步”卡用绿色箭头或星标强调。旁边同桌继续写题，气氛安静。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，温暖、有成就感。
Composition/framing: 中景，小宇在画面中心，手正在写；屏幕在一侧，草稿纸在前景，动作清楚。
Lighting/mood: 明亮、安心，像终于找到入口。
Color palette: 米白纸面、黑线、绿色校服、蓝色屏幕、黄色卡片、绿色强调。
Visible text: 屏幕卡片上可以出现短中文“第一步”。不要出现最终答案，不要出现其他可读文字，算式用不可读线条表示。
Constraints: 画面要清楚表现“不是给答案，是帮孩子开始”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要出现最终答案，不要奖杯，不要老师批评，不要成人化学习工具广告。
