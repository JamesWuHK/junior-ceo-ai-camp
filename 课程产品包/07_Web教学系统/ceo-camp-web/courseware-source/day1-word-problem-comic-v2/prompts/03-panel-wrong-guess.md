Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“孩子随便写了一步又擦掉，发现乱猜让题目更乱”。
Scene/backdrop: 小学教室课桌近景，数学练习纸和草稿纸铺在桌上，橡皮屑很多。
Subject: 小宇，10 岁中国男孩，短黑发，绿色校服外套，一手拿橡皮擦掉一大片草稿，一手扶着额头，表情懊恼但不夸张。草稿纸上有被擦掉的数字线条、箭头和问号形状，全部不可读。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，动势清楚。
Composition/framing: 桌面近景为主，小宇上半身在画面上方，橡皮屑和被擦掉的草稿在前景，表现“越猜越乱”。
Lighting/mood: 温暖但略烦躁，真实学习卡点。
Color palette: 米白纸面、黑线、绿色校服、浅灰橡皮屑、少量红色问号点缀。
Text: 不要在图片里写任何字，不要气泡文字，所有纸面内容都用不可读线条。
Constraints: 画面要让孩子看懂“乱猜一步，后面更乱”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要把孩子画成失败者，不要哭泣，不要出现红叉成绩，不要成人讲解图。
