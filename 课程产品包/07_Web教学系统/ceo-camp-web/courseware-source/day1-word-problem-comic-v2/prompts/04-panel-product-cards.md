Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“一个简单产品把长应用题拆成四张卡片，帮孩子看清第一步”。
Scene/backdrop: 课桌上的平板或笔记本屏幕，旁边有数学练习纸、草稿纸、铅笔和橡皮。
Subject: 屏幕中间是一个简单网页原型：左边是一张长题纸图标，右边变成四张清楚卡片。四张卡片写清楚短中文标签：谁、已知、要求、第一步。小宇在旁边用手指点屏幕，表情像“原来可以这样看”。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，界面像孩子能做出来的简单页面，不要成人 SaaS 风格。
Composition/framing: 屏幕占画面中心，长题纸到四张卡片之间有手绘箭头，桌面学习用品环绕。
Lighting/mood: 清楚、安心，有“乱线被摆整齐”的感觉。
Color palette: 米白纸面、黑线、淡蓝屏幕、黄色卡片、绿色第一步箭头。
Visible text: 只允许出现这些短中文：谁、已知、要求、第一步。不要出现其他文字。
Constraints: 画面要像一个帮助开始的小产品，不是自动给答案工具。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要出现答案结果，不要复杂公式，不要后台、API、数据库、管理、审核等系统词。
