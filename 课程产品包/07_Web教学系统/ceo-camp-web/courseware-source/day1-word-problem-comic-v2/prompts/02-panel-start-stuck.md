Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“旁边同学已经开始写算式，小宇却不知道第一步”的对比。
Scene/backdrop: 小学数学教室，两张相邻课桌，桌面有练习纸、草稿纸、铅笔和橡皮。
Subject: 小宇，10 岁中国男孩，短黑发，绿色校服外套，皱眉看着草稿纸，草稿纸上有几条乱线和擦痕。旁边同桌已经写了两行简单算式，用不可读线条和数字形状表示，不要真实可读文本。同桌专心写题，没有看小宇。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，表情真实，课堂友好。
Composition/framing: 俯视加中景，小宇和同桌形成左右对比；小宇的空白草稿纸和同桌的算式纸都清楚。
Lighting/mood: 温暖课堂光，有一点“别人开始了，我还没动”的着急感。
Color palette: 米白纸面、黑线、绿色校服、淡黄练习纸、橙色小强调。
Text: 不要在图片里写任何字，不要气泡文字，所有文字用不可读涂线表达。
Constraints: 画面要表达“不知道怎么开始”，不是“不努力”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要嘲笑，不要排名，不要老师训话，不要考试倒计时。
