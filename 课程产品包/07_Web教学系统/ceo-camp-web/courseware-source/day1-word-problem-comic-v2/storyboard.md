# 应用题拆题板：五格连环画分镜

标题：字太多，小宇不知道先看哪句

| 分镜 | 主画面 | 画面标题 | 连环画文字 |
|---|---|---|---|
| 1 | 教室里，小宇盯着一大段应用题，笔停在空中，题目纸像一堵文字墙。 | 字好多，我先看哪句？ | 小宇不是怕数学，他是被一大段题目挡住了。 |
| 2 | 旁边同学已经写出算式；小宇的草稿纸上只有乱线和擦痕。 | 我不是不会算，是不知道怎么开始。 | 别人已经开始算，他还没找到第一步，越看越急。 |
| 3 | 小宇随手写了一个算式，又皱眉停住，橡皮擦掉一大片。 | 乱猜一步，后面更乱。 | 随便猜一个算式，写到后面就发现对不上。 |
| 4 | 应用题拆题板把长题拆成四张卡：谁、已知、要求、第一步。 | 先把题目摆整齐。 | 拆题板不直接给答案，只把题目拆成能看清的四块。 |
| 5 | 小宇看着第一步卡片，开始写自己的算式，表情放松。 | 不是给答案，是帮我开始。 | 看见第一步以后，小宇终于可以自己动笔了。 |

收束句：

先帮小宇迈出第一步，就是一个产品的开始。
