# 应用题拆题板：连环画内容分析

## 目标

用一个孩子被长应用题卡住的故事，让孩子看见“不是不会算，而是不知道先从哪一句开始”的学习麻烦，再看到一个小产品怎样把题目拆成能下手的四块。

## 受众

8-12 岁孩子。画面先让孩子看懂小宇为什么停住，再让产品出现帮助他开始，不把“学习效率”“知识结构化”等成人词放到画面里。

## 角色

- 小宇：10 岁男孩，短黑发，绿色校服外套，桌上有铅笔、橡皮和数学练习纸。表情从发懵、着急，到放松。
- 同桌：在旁边已经开始写算式，形成对比，但不嘲笑。
- 老师：只在远处温和经过，不做批评画面。

## 叙事节拍

1. 数学练习课，小宇盯着一大段题，笔停住。
2. 同桌已经写了两行，小宇草稿纸上只有乱线。
3. 小宇随便写一步又擦掉，发现乱猜更乱。
4. 应用题拆题板把长题拆成“谁、已知、要求、第一步”四张卡。
5. 小宇看见第一步，开始自己写算式。

## 画风

- 一页五格连环画，4:3 单格主画面，适合教师端课件和全屏投影。
- 温暖手绘 sketchnote / 粉笔感，纸面背景，清楚表情和动作。
- 图片里尽量不放文字，网页层负责中文 caption。
