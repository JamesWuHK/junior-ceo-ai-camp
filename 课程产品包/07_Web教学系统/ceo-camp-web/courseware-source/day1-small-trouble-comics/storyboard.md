# 从一个小麻烦开始：四个项目连环画分镜

## 规格

- 风格：sketchnote 手绘教育风格
- 布局：每个项目一页，四格连环画
- 比例：4:3 横版
- 文字：中文，短句，大字

## 01 上学出门检查台

标题：早上又漏带了

1. 乐乐站在家门口，鞋穿好了，书包背着。妈妈问：“美术彩笔带了吗？”
2. 乐乐脑子里同时出现课表、通知、作业本三个小纸片。他说：“我记得有体育，也好像有美术。”
3. 出门检查台出现。乐乐把课表和通知贴进去，页面变成三栏清单。
4. 乐乐勾出跳绳和彩笔，安心出门。短句：少漏带，少慌张。

## 02 应用题拆题板

标题：长应用题读到一半就乱

1. 小宇在数学练习课上盯着一大段应用题，笔停住。
2. 旁边同学开始写算式，小宇说：“我不是不会算，是不知道先看哪句。”
3. 应用题拆题板把题目拆成：谁、已知、要求、第一步。
4. 小宇写下第一步算式。短句：不是给答案，是帮我开始。

## 03 四格漫画分镜台

标题：脑子里有故事，纸上排不出来

1. 安安午休想画“铅笔盒半夜开会”，第一格画完就停住。
2. 她擦了又画，旁边同学已经画到第三格。她说：“我是不知道怎么排。”
3. 四格漫画分镜台给出四格草稿：醒来、抱怨、争论、橡皮发言。
4. 安安改掉最后一句，笑着继续画。短句：草稿先出来，我再改。

## 04 校园活动组队板

标题：想参加活动，却找不到同伴

1. 航航想报名无人机体验，报名规则写着“三人一组”。
2. 他问了三个人都没凑齐；另一边琪琪也想去，但不知道航航在找人。
3. 校园活动组队板出现一张活动卡：无人机体验，还缺 1 人。
4. 琪琪点“我也想加入”，三人组凑齐。短句：想参加的人看见彼此。
