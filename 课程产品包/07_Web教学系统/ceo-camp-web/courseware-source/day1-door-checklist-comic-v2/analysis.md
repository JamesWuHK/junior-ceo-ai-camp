# 上学出门检查台：连环画内容分析

## 目标

用一个孩子早上出门漏带东西的故事，让孩子先感受到“这个麻烦我也可能遇到”，再看到一个小产品怎样帮人少慌一次、少漏带一样东西。

## 受众

8-12 岁孩子。画面和文字都从孩子视角出发，不放老师讲稿，不讲抽象概念。

## 角色

- 乐乐：10 岁男孩，短黑发，黄色连帽卫衣，蓝色书包。表情容易被看懂：疑惑、慌张、不好意思、放松。
- 妈妈：温和、不催促压迫，只是提醒问题。
- 同桌：在美术课上递给乐乐几支彩笔。

## 叙事节拍

1. 家门口，乐乐正要出门，被问“彩笔带了吗？”
2. 课表、通知、作业要求同时挤进脑袋。
3. 到了美术课，真的没带彩笔，只好借同桌的。
4. 出门检查台把分散信息整理成三栏。
5. 第二天，乐乐照着清单拿到跳绳和彩笔，安心出门。

## 画风

- 一页五格连环画，适合课件 16:9 展示。
- 主画面用温暖手绘 sketchnote 风格：纸面背景、铅笔线、彩色马克笔、少量黄色强调。
- 图片内尽量不放文字，文字说明由网页层排版，保证中文清楚。
