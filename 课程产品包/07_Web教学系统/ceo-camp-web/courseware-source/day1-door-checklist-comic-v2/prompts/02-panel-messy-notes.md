Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“早上出门前，课表、通知、作业要求全挤在脑子里”的混乱感。
Scene/backdrop: 家门口附近，半开的蓝色书包放在矮凳上，旁边有鞋柜和书桌一角。
Subject: 乐乐，10 岁中国男孩，短黑发，黄色连帽卫衣，表情慌张又努力回想。头顶周围飞着三张没有文字的纸片图标：课表格子、手机通知图标、作业本图标。书包里能看到课本，但明显缺少彩笔盒和跳绳。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，线条活泼，带一点小箭头和涂鸦动势。
Composition/framing: 乐乐半身在中心，书包在前景，三张纸片绕着头顶旋转，形成可视化的“脑子乱了”。
Lighting/mood: 温暖但略紧张，像早上赶时间。
Color palette: 米白纸面、黑线、黄色卫衣、蓝色书包，纸片用淡黄、淡蓝、淡绿区分。
Text: 不要在图片里写任何字，不要气泡文字，留给网页层配字幕。
Constraints: 画面必须清楚表现“信息分散，孩子想不全”，不要真的写课表内容。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要出现手机聊天详情，不要出现真实学校名，不要出现后台、管理、系统字样。
