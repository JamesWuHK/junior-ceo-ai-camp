Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“美术课上，乐乐翻书包发现彩笔没带，只好向同桌借”的尴尬时刻。
Scene/backdrop: 小学美术教室，桌上有画纸、颜料盘和几盒彩笔，背景有孩子们正在画画的模糊身影。
Subject: 乐乐，10 岁中国男孩，短黑发，黄色连帽卫衣，蓝色书包打开放在椅边，他低头翻书包，表情不好意思。同桌从旁边递来几支彩笔，动作友好。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，温暖、真实，不责备孩子。
Composition/framing: 近中景，乐乐和同桌占主要画面，空空的书包和彩笔借出的动作清楚。
Lighting/mood: 温暖课堂光，带一点“尴尬但有人帮忙”的情绪。
Color palette: 米白纸面、黑线、黄色卫衣、蓝色书包，彩笔用明亮小色块。
Text: 不要在图片里写任何字，不要气泡文字，留给网页层配字幕。
Constraints: 画面要让孩子看懂“漏带带来了真实麻烦”，但不要羞辱乐乐。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要老师批评，不要同学嘲笑，不要哭泣夸张，不要考试场景。
