# 上学出门检查台：五格连环画分镜

标题：早上出门前，脑子突然乱了

| 分镜 | 主画面 | 文字说明 |
|---|---|---|
| 1 | 家门口，乐乐背着书包，一只手放在门把手上；妈妈从厨房探头，墙上时钟指向 7:24。 | 彩笔带了吗？ |
| 2 | 乐乐脑袋旁边飞出三张纸片：课表、通知、作业本；书包半开，跳绳和彩笔不在里面。 | 体育、科学、美术，全挤在一起了。 |
| 3 | 美术课桌上，乐乐打开书包找不到彩笔，同桌递来几支笔，乐乐有点不好意思。 | 我不是故意忘的，是早上想不全。 |
| 4 | 一个简单页面出现：左边放进课表和通知，右边变成三栏清单。 | 清单分三栏：带什么、查什么、到校先做什么。 |
| 5 | 第二天早上，乐乐照着清单勾选，跑回阳台拿跳绳，再笑着出门。 | 东西带齐了，出门就不慌了。 |

收束句：

先帮乐乐少慌一次，就是一个产品的开始。
