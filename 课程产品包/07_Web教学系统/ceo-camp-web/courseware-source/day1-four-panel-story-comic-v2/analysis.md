# 四格漫画分镜台：连环画内容分析

## 目标

用一个孩子有好点子却排不出四格漫画的故事，让孩子看见“创作不是没有想法，而是卡在顺序和收尾”，再看到一个小产品怎样先给可改草稿。

## 受众

8-12 岁孩子。画面要保护孩子自己的创意，不把 AI 讲成替孩子完成作品，而是先帮她把故事排出来。

## 角色

- 安安：10 岁女孩，黑色短发或低马尾，橙色针织背心，喜欢画画，桌上有画纸、彩笔、铅笔盒。
- 文具角色：尺子、橡皮、自动铅笔等，作为她漫画里的小角色出现，表情可爱但不幼稚。
- 同学：背景里有同学画到第三格，用来表现进度差异，不嘲笑。

## 叙事节拍

1. 午休时，安安画出第一格，铅笔盒里的文具半夜探头。
2. 第二格空着，橡皮屑很多，她不知道怎么排下去。
3. 第一格擦了又画，故事卡在中间。
4. 四格漫画分镜台给出四张草稿卡：醒来、抱怨、争论、橡皮发言。
5. 安安把最后一句改成自己的笑点，继续画完。

## 画风

- 一页五格连环画，4:3 单格主画面。
- 温暖手绘 sketchnote / 粉笔感，带一点漫画感和文具拟人，但不做低幼卡通。
- 图片里不放可读文字，中文 caption 放网页层。
