Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“一个简单产品把故事点子排成四张可修改的分镜草稿卡”。
Scene/backdrop: 教室课桌上的平板或笔记本屏幕，旁边是画纸、彩笔、铅笔盒和橡皮。
Subject: 屏幕中间是一个简单网页原型：左边是一个故事点子卡图标，右边出现四张草稿卡。四张卡写清楚短中文标签：醒来、抱怨、争论、橡皮。安安在旁边用手指点屏幕，表情像“可以继续了”。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，界面像孩子能理解的小工具，不要成人 SaaS 风格。
Composition/framing: 屏幕占中心，四张草稿卡横向或网格排列，画纸和彩笔在前景。
Lighting/mood: 清楚、轻松、有“草稿出来了”的开心。
Color palette: 米白纸面、黑线、淡蓝屏幕、黄色草稿卡、橙色和绿色小强调。
Visible text: 只允许出现这些短中文：醒来、抱怨、争论、橡皮。不要出现其他文字。
Constraints: 画面要表达“先给可改草稿，不是替孩子画完”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要出现自动完成整篇漫画，不要复杂软件界面，不要后台、API、数据库、管理、审核等系统词。
