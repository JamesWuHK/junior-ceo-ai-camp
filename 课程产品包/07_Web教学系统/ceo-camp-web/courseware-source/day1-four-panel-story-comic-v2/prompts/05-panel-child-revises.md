Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“孩子拿到草稿后自己改笑点，继续画完四格漫画”的变化。
Scene/backdrop: 午休教室课桌，桌上有四格画纸、彩笔、铅笔盒和简单分镜台屏幕。
Subject: 安安，10 岁中国女孩，黑色低马尾，橙色针织背心，开心地在第四格继续画，表情专注。画纸上四格都已有清楚画面轮廓，最后一格被她加了新的表情和动作。桌上的尺子、橡皮、自动铅笔像在小小鼓掌，但不要文字。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，温暖、有成就感。
Composition/framing: 桌面中景，安安画画动作在中心，四格画纸和屏幕都可见，文具小角色增加趣味。
Lighting/mood: 明亮、轻松，创作继续往前走。
Color palette: 米白纸面、黑线、橙色背心、彩笔多色、淡黄色纸张。
Text: 不要在图片里写任何字，不要气泡文字。
Constraints: 画面要清楚表现“草稿先出来，孩子再改成自己的作品”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要奖杯，不要让 AI 替孩子画完，不要商业海报感。
