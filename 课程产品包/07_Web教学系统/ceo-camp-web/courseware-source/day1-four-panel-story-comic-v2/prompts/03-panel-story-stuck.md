Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“第一格被擦了又画，故事角色像在等下一步”的创作卡点。
Scene/backdrop: 午休课桌近景，画纸、橡皮屑、彩笔和铅笔盒散在桌上。
Subject: 安安，10 岁中国女孩，黑色低马尾，橙色针织背心，正在擦改第一格，表情纠结。画纸上的尺子、橡皮、自动铅笔小角色像站在纸边等待出场，用拟人表情表现“等安排”，但不要文字。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，轻松有趣。
Composition/framing: 桌面近景，画纸第一格有擦痕，第二三四格空白，文具小角色在画纸边缘形成可爱视觉焦点。
Lighting/mood: 温暖、有一点好笑的卡顿感。
Color palette: 米白纸面、黑线、橙色背心、彩色马克笔、浅灰橡皮屑。
Text: 不要在图片里写任何字，不要气泡文字。
Constraints: 画面要让孩子看懂“故事卡在中间，不知道怎么往后排”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要把 AI 或电脑提前放进画面，不要低幼夸张，不要成人创意会议。
