Use case: illustration-story
Asset type: courseware comic panel image
Primary request: 生成一张儿童教育连环画主画面，表现“孩子有故事点子，但第二格不知道画什么，四格排不出来”。
Scene/backdrop: 午休教室课桌，画纸分成四格，第一格有文具探头的小画，第二格空白，桌边有橡皮屑和彩笔。
Subject: 安安，10 岁中国女孩，黑色低马尾，橙色针织背心，盯着第二格空白，手拿铅笔停住，表情发愁。旁边一位同学在背景中已经画到第三格，但只作模糊对比，不抢画面。
Style/medium: 手绘 sketchnote 儿童教育风格，纸面背景，铅笔线条和彩色马克笔，真实课堂感。
Composition/framing: 俯视桌面加安安半身，四格画纸清楚，第二格空白要明显。
Lighting/mood: 温暖但有一点卡住的着急。
Color palette: 米白纸面、黑线、橙色背心、淡蓝课桌、彩笔颜色点缀。
Text: 不要在图片里写任何字，不要气泡文字，画纸上的内容不要出现可读文字。
Constraints: 画面要表达“不是没想法，是排不成四格”。没有水印，没有 logo，没有英文，没有乱码文字。
Avoid: 不要嘲笑，不要老师催促，不要把同学画成竞争对手。
