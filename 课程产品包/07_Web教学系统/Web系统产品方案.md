# 少年CEO AI 创业营 Web教学系统产品方案

## 1. 产品定位

Web教学系统是整个营的课堂中控和作品沉淀系统。它不是单纯的招生网站，也不是课后作品墙，而是从 Day 1 开营到 Day 3 终极作品秀全程使用的教学平台。

一句话定位：

> 老师用它讲故事、做演示和控场，孩子用它完成实验任务和提交作品，家长观察员用它观看成果和评分。

## 2. 为什么必须用一个系统

如果不用系统，课程现场会出现三个问题：

- 课件在老师电脑里，互动在纸上，作品在孩子电脑里，终极作品秀在 PPT 里，资料很容易散。
- 老师无法实时看到每组进度，不知道哪组还没采访、哪组小机关卡住、哪组只有一个人在做。
- 结营展示难以统一呈现，家长看到的是零散截图和口头介绍，而不是完整的项目成长过程。

Web系统要解决的是：

- 课程节奏统一。
- 学生任务统一。
- 团队进度透明。
- 作品展示完整。
- 家长看到孩子 3 天的真实成长轨迹。

## 3. 使用角色

| 角色 | 使用端 | 核心权限 |
|---|---|---|
| 主讲老师 | 教师入口/大屏展示 | 切换课件、发布任务、控制计时、展示作品、开启投票 |
| 产品导师 | 教师入口内支持区 | 查看用户采访、产品定义、小机关范围，给出导师批注 |
| 工具支持 | 教师入口内支持区 | 查看技术路线、卡点登记、小机关链接，处理工具问题 |
| 运营支持 | 后台管理 | 签到、照片授权、分组、作品发布审核 |
| 学生 | 学生端 | 填任务卡、提交作品、互评、查看团队进度 |
| 家长观察员 | 展示端/评分端 | 查看最终作品、故事发布评分、留言反馈 |

产品入口只保留两类：教师入口和学生入口。现场助教、产品导师、工具支持、运营支持是人员角色，不单独拆第三个入口；他们按权限进入教师入口或后台管理。

## 4. 核心模块

### 4.0 三天日程总控

用途：把 3 天所有教学时段放进系统，成为老师和现场支持人员共同使用的排课中控。

功能：

- 展示 Day 1、Day 2、Day 3 的完整时间表。
- 教师端首页直接按 D1 / D2 / D3 展示日程；这是老师进入系统后的主线。
- 每个时段绑定：教学模块、老师动作、学生任务、教学资源、产出物。
- 支持点选时段查看执行细节。
- 支持在当前环节中直接进入资源：打开课件、全屏演示、发布任务、团队资料、展示、评分、后台审核。
- 支持标记当前时段、已完成时段和需要现场支持关注的时段。
- 与 HTML PPT 授课台联动：老师切到某个时段后，系统能打开对应课件页、发布对应任务和更新倒计时。

设计原则：

- 老师看到的是课堂节奏。
- 现场支持人员看到的是下一步该支持哪一组。
- 运营看到的是照片授权、午餐休息、故事发布彩排等现场节点。
- 学生端只显示当前任务，不暴露复杂日程后台。
- PPT 和大屏展示只放孩子能直接看的内容；老师讲稿、控场提醒、审核规则放在教师控制区、备注或讲稿文档中，不直接出现在全屏演示画面。
- `PPT授课`、`学生工作台`、`团队空间`、`作品展厅`、`评分中心` 不作为教师端一级导航，而是作为日程时段上的教学资源入口。
- 信息按层级逐步展开：左侧黑色区域先选 D1/D2/D3，再显示当天环节清单；右侧白底区域始终显示当前环节的课件或简明环节页。

### 4.0 官网双入口对接

`camps.wanli.wiki` 保留两个课堂入口：

- 教师入口：官网 `teacher.html`，进入教师课件、课程目录、活动发起、大屏控制和后台管理。
- 学生入口：官网学生入口或课堂二维码，进入学生当前任务页，只显示上传照片、未来职业、提交、团队任务等学生需要操作的内容。

入口边界：

- 教师入口可以看到三天日程、课件、学员名单、作品审核、发布状态。
- 学生入口不能看到教师课件、后台管理、评分中心和其他学生的隐私提交内容。
- 同一课堂活动由教师端发起，学生端只接收当前任务。

### 4.1 HTML PPT 授课台

用途：主讲老师的课堂指挥台。教师端的主形态不是传统后台，而是 HTML PPT 授课模式。

功能：

- 当前课程阶段。
- 教师端左侧三天日程：按 D1/D2/D3 快速定位每个教学环节及其资源。
- 每个课件支持“打开课件”和“全屏演示”两种入口。
- HTML PPT 页展示和缩略页导航。
- 在 PPT 页内直接发起活动：扫码、投票、留言墙、任务提交、照片墙、评分。
- 倒计时。
- 发布任务到学生端。
- 查看每组提交状态。
- 一键进入作品展示或作品秀模式。

建议设计：

- 左侧黑色区域为课程流程导航。
- 左侧先显示 D1/D2/D3 快速切换，再显示当前选中当天的环节清单。
- 点击左侧环节后，右侧白底区域立即切换到对应 HTML PPT 课件；没有独立课件的环节显示简明环节页。
- 右侧白底区域是授课舞台，默认展示课件内容和课件内活动按钮。
- 当前课件可一键切换到全屏演示模式。
- 状态看板、作品墙、评分表不在右侧默认铺开，只有老师点击对应资源或课件内活动时才展开。
- 中间为 HTML PPT 大屏课件页，这是老师讲课的主舞台。
- PPT 页下方或页内提供“本页可发起活动”按钮。
- 老师不需要离开 PPT 去后台找功能，活动应从当前课件页直接发起。

### 4.1.1 教师端功能按钮规范

教师端按钮要固定成少数几类，不允许每个课件页随意命名。老师上课时需要的是“我现在要发布、互动、看进度、投屏、计时还是评分”，具体任务名称放在按钮的辅助文字里。

| 按钮功能 | 出现位置 | 用途 | 示例辅助文字 |
|---|---|---|---|
| 打开课件 | 左侧环节清单、当前 PPT 页 | 进入某个教学模块的 HTML PPT | 未来照相馆、便利贴侦探 |
| 全屏演示 | 左侧环节清单、当前 PPT 页 | 把当前课件或当前页切到大屏授课模式 | 第 1 页故事页 |
| 查看详情 | 左侧环节清单 | 查看没有独立课件的课堂时段细节 | 团队组建、午餐、彩排 |
| 上一页/下一页 | 当前 PPT 页 | 翻动当前模块的多页课件 | 故事页、AI 演示、动手实验、作品秀 |
| 发布任务 | 当前 PPT 页 | 把任务发到学生端当前任务 | AI 验证卡、小机关卡、故事发布五步卡 |
| 发起互动 | 当前 PPT 页 | 发起投票、判断、课堂提问 | 猜职业投票、真假判断、交换方式投票 |
| 打开看板 | 当前 PPT 页、教师支持区 | 查看提交、卡点、进度和现场支援 | 采访进度、卡点墙、进度看板 |
| 投屏展示 | 当前 PPT 页、展示端 | 上大屏展示审核后的照片、作品、投票结果 | 未来职业照墙、线索墙、价值交换榜 |
| 启动计时 | 当前 PPT 页 | 控制 workshop、彩排、限时任务 | 8 分钟倒计时、彩排计时 |
| 进入评分 | 当前 PPT 页、评分中心 | 进入 Day 3 观察员评分流程 | 观察员评分 |

按钮视觉层级：

- 主要按钮只用于“打开课件、全屏演示、发布任务、进入评分”。
- 普通按钮用于“发起互动、打开看板、启动计时”。
- 投屏展示用独立强调色，避免和发布任务混淆。
- 每个 PPT 页最多放 3 个本页功能按钮，防止老师上课时选择过多。

### 4.2 课件展示

用途：替代传统 PPT，所有课件内容直接在系统内展示。

功能：

- HTML PPT 作为教师授课主界面。
- 破冰课件和模块 1-7 的课件页面。
- 每个模块不是单页，而是一套多页 HTML PPT。
- 每页都有明确页面类型：故事引入、AI 功能演示、学生动手实验、学生作品秀。
- 每页对应一个课堂动作和一个系统状态，而不是只展示静态文字。
- 面向孩子的课件表达要优先使用故事、角色任务、现场演示和小实验，不使用大人开会式表达。
- PPT 页面不写老师完整话术，只放标题、视觉材料、关键词、互动问题、任务说明和活动入口；完整讲稿进入教师备注或讲稿文档。
- 专业名词可以正常进入课件，例如产品、价格、大模型、用户、原型、MVP；第一次出现时用孩子能理解的例子解释。
- 课件内教学流程条：例如破冰课件显示“预热照片秀、扫码采集、语音说理想、AI 生成、审核投屏、转场提问”。
- 预热素材展示：开场先展示几张 AI 生成职业照，帮助孩子进入活动状态。
- 活动组件嵌入课件页：老师在讲到某一页时，可直接发起对应活动。
- 可嵌入演示视频、图片、案例、提示词。
- 每个模块最后一页固定为“现在请完成”任务页。
- 支持大屏展示和老师备注。

### 4.2.1 PPT 内活动发起

每个活动都应该绑定在具体 PPT 页上，而不是散落在后台菜单里。

| PPT 页类型 | 页面用途 | 可发起活动 |
|---|---|---|
| 故事页 | 用故事、角色任务、问题情境把孩子带进课堂 | 投票、提问、留言墙、切换下一页 |
| AI 演示页 | 老师演示 AI 生图、生成网页、改写咒语、验证结果等 | 打开演示、发送观察问题、收集学生发现 |
| 动手实验页 | 学生动手时老师控场，现场支持人员看卡点和完成度 | 发布任务、查看提交状态、启动倒计时、打开卡点墙 |
| 作品秀页 | 展示审核后的照片、作品、投票结果、故事发布页面 | 投屏作品、轮播作品墙、同伴反馈、评分 |
| 故事发布页 | Day 3 用故事讲清作品，不做大人开会式汇报 | 开始评分、提交观察员问题、汇总分数 |

### 4.3 学生任务工作台

用途：把纸质任务卡数字化，学生所有关键产出都在这里完成。

任务类型：

- 未来照相馆任务卡。
- 烦人墙便利贴。
- AI 验证卡。
- 用户采访卡。
- 产品一句话卡。
- Prompt 五句卡。
- 小机关功能卡。
- 技术路线卡。
- 用户测试记录卡。
- 星星币价值卡。
- 故事发布五步卡。
- AI 指挥官反思卡。

设计原则：

- 表单要短。
- 每次只显示当前任务。
- 低龄孩子也能看懂。
- 支持老师查看和批注。

### 4.4 课堂互动区

用途：把课堂热度和反馈集中起来。

互动类型：

- 扫码采集：孩子扫码进入当前任务页，上传照片，选择或语音录入理想职业，点击提交。
- 语音输入：低龄孩子可用语音说理想职业，系统转文字并提取关键词；也可以直接点选预设职业。
- 大屏照片墙：课前名单先生成名字占位符，未来职业照经老师审核后替换占位展示。
- 快速投票：职业选择、烦人墙投票、项目方向投票。
- 弹幕/留言墙：未来 CEO 宣言、AI 验证发现、卡点登记。
- 同伴反馈：试玩后给别组 1 条建议。
- 故事发布提问：观察员和同学提交问题。

### 4.5 团队项目空间

用途：每组的创业工作台。

每组空间包含：

- 团队名称和角色。
- 目标用户。
- 真实痛点。
- 采访证据。
- 产品一句话。
- 小机关核心动作。
- 技术路线。
- 产品链接/截图/录屏。
- 测试反馈。
- 星星币价值方式。
- 故事发布稿。

### 4.6 教师入口内的进度看板

用途：让老师和现场支持人员知道该去哪一组帮忙。

看板字段：

- 是否完成分组。
- 是否提交未来宣言。
- 是否有 3 条采访记录。
- 是否完成产品一句话。
- 是否选择技术路线。
- 小机关是否可打开。
- 是否完成用户测试。
- 是否提交故事发布稿。
- 当前卡点。

### 4.7 作品展厅

用途：Day 3 终极作品秀和课后家长展示。

展示内容：

- 团队海报。
- 产品一句话。
- 小机关链接或演示截图。
- 用户采访摘要。
- 迭代前后变化。
- 故事发布视频/照片。
- 观察员反馈。
- 每个孩子的个人贡献。

展示模式：

- 课堂大屏：按作品秀顺序展示。
- 家长浏览：每个团队一个作品页。
- 课后作品集：只展示经过审核的内容。

### 4.8 作品秀评分与奖项

用途：把评分、投票和奖项收口。

评分维度：

- 用户真实度。
- 小机关完成度。
- AI 协作质量。
- 故事表达。
- 团队故事发布。

输出：

- 观察员评分。
- 同伴投票。
- 团队奖项建议。
- 个人能力标签。

## 6. 关键数据对象

| 数据对象 | 说明 |
|---|---|
| Camp | 一个营期，如 2026 北京暑假第 1 期 |
| User | 教师/现场支持、学生、家长观察员 |
| Team | 小组和角色分工 |
| Module | 课件模块和课堂阶段 |
| Task | 当前发布的课堂任务 |
| Submission | 学生或团队提交内容 |
| Project | 团队产品资料 |
| Asset | 图片、截图、录屏、海报等文件 |
| VoiceSubmission | 学生语音、识别文本、职业关键词和审核状态 |
| Feedback | 用户测试、同伴反馈、导师批注 |
| Score | 观察员评分和同伴投票 |
| Showcase | 经过审核的最终展示页 |

## 7. 隐私与安全原则

- 未成年人照片必须有家长授权。
- 照片和真实姓名、学校、手机号等敏感信息分离存储。
- 学生端不能看到其他孩子未公开的个人资料。
- 作品发布前必须经过老师或后台运营支持审核。
- AI 工具 API Key 不进入学生端。
- 家长展示页只开放审核后的内容。
- 原始照片默认课后删除，保留成品需家长同意。
- 语音原始文件默认活动后删除，只保留必要的识别文本和职业关键词。
- 正式生产环境优先部署在国内用户友好的云环境，不依赖海外访问链路完成课堂主流程。
- 儿童照片和作品文件默认放私有对象存储，不使用公开 Bucket 或公开图床。
- 中国大陆公开访问的正式域名应提前完成 ICP 备案。

## 8. MVP 版本范围

第一版系统只做能支撑 3 天营运转的功能：

- HTML PPT 授课台。
- Web 课件展示与 PPT 内活动发起。
- 学生当前任务提交。
- 团队项目空间。
- 教师入口内的进度看板。
- 作品展厅。
- 作品秀评分。

暂不做：

- 复杂 LMS 课程库。
- 长期学员成长档案。
- 真实支付。
- 复杂消息系统。
- 开放式社交功能。

## 9. 成功标准

系统上线后，课程现场应达到：

- 老师能用系统完成全部课件展示，不再依赖 PPT。
- 每个关键课堂任务都能在系统内提交。
- 现场支持人员能实时看到每组进度。
- Day 3 终极作品秀时，每组都有一个统一作品页。
- 家长课后能看到孩子作品、照片、团队贡献和导师反馈。
- 国内营地网络下，30 人同时访问、提交任务、上传截图和参与评分不影响课堂节奏。
