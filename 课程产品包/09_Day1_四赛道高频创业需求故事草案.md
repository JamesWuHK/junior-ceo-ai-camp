# Day 1｜四赛道高频创业需求故事草案

用途：用于重写「选方向，找想帮的人」这一教学环节前的内容确认。先不进 PPT。

这一版不急着给孩子解决方案。每个项目先讲清楚：

- 谁经常遇到这个麻烦。
- 麻烦在什么时间、什么场景里发生。
- 现在的办法为什么不够好。
- 如果真的解决了，谁会愿意付出时间、推荐、星星币，甚至付费。
- 孩子下一步应该去问谁、问什么。

课堂上给孩子看的语言要保留故事感；给老师看的判断要讲清产品和商业逻辑。

## 选项目的判断标准

一个项目值得孩子继续做，至少要过 4 个问题：

1. 这个麻烦是不是经常发生？
2. 遇到的人会不会真的烦？
3. 现在的办法是不是不够好？
4. 如果有人帮他解决，他愿不愿意付出一点东西来换？

这里的“付出一点东西”不一定是钱。对孩子来说，可以是：

- 每天都打开用。
- 推荐给同学。
- 给出星星币。
- 愿意把自己的真实问题告诉这个产品。
- 家长或老师觉得省心，愿意买单或推广。

## 四条赛道总览

| 赛道 | 这一赛道要找的需求 | 更可能付出价值的人 |
|---|---|---|
| 生活帮手 | 每天重复发生、会让孩子和家长都着急的生活小麻烦 | 孩子、家长 |
| 学习工具 | 不是不会学，而是卡在开始、复习、表达、检查这些具体步骤 | 孩子、家长、老师 |
| 创意工坊 | 有想法但做不出来，卡在开头、规则和把文字变画面 | 孩子、家长、社团老师 |
| 校园社区 | 同学之间想学、想换、想点单的小需求 | 孩子、同学、社团老师 |

## 技术实现原则：孩子对 WorkBuddy 说清需求

时间有限，课堂不把孩子训练成工具操作员。孩子要学的是：

```text
我想帮谁？
他在什么时候卡住？
我想先帮他完成哪一步？
别人用完以后应该看到什么结果？
第一版哪里不对，我要怎么改？
```

工具路线可以统一成：

```text
孩子语音说需求
  ↓
WorkBuddy 整理成产品任务单
  ↓
选择一个合适的生成工具或模板
  ↓
生成可打开、可试玩、可演示的第一版
  ↓
孩子看结果，继续说要改哪里
```

WorkBuddy 在这里不是另一个要孩子学习菜单的工具，而是课堂里的“总入口”。孩子用语音或短句说需求，WorkBuddy 把它整理成：

- 产品一句话。
- 用户和场景。
- 核心动作。
- 页面结构。
- AI / 智能体规则。
- 给秒哒、扣子或其他工具的生成提示词。
- 修改指令。

### 原型交付分级

课堂上不要一上来承诺“完整 App”或“完整小程序”。每个项目先选一个交付级别。

| 级别 | 交付物 | 适合情况 | 谁来兜底 |
|---|---|---|---|
| A. 浏览器网页 | H5 / HTML 小工具，扫码或链接打开 | 大多数项目第一版 | WorkBuddy + 秒哒 / 网页模板 |
| B. 智能体页面 | 一个能问答、追问、给建议的产品脑袋 | 学习工具、创意工具、陪练类 | WorkBuddy + 扣子 |
| C. 卡片墙 / 看板 | 小课卡、交换卡、点单卡、完成状态 | 校园社区类 | 课堂系统模板 / WorkBuddy |
| D. 微信可体验版 | 在微信里能打开的 H5，像小程序一样体验 | 需要手机扫码体验 | H5 链接 + 微信浏览器 |
| E. 微信小程序原型 | 用小程序模板或智能体工具生成，能演示核心流程 | 时间允许、工具可用、老师能兜底 | WorkBuddy agent + 秒哒 / 小程序生成工具 / 技术支持 |

默认路线是 A-D。E 只作为进阶路线，不要求每组都做。

关键判断：

- 孩子不用学习小程序开发。
- 孩子不用配置云开发、登录、支付、审核发布。
- 孩子只需要把需求说清楚，并能看着第一版说出哪里要改。
- 如果要做微信小程序，也应该由 WorkBuddy agent 或老师技术支持接管底层操作。
- 如果某个工具需要复杂操作，就让 WorkBuddy agent 去控制工具；孩子不直接陷进工具菜单里。
- 三天营的第一目标不是“上线完整产品”，而是让孩子用自己的需求语言，推动一个能体验的产品原型出现。

### 课堂还需要补的能力

为了让这条路线跑通，课程里要补 3 个小知识点。

1. 产品任务单

孩子要会把语音需求说成 5 句话：

```text
这个产品给谁用？
他什么时候会打开？
他要完成哪一个动作？
页面上要有什么？
用完以后看到什么结果？
```

2. 工具路线选择

老师要教孩子选路线：

```text
要做记录和按钮：走网页 / 秒哒。
要做问答和陪练：走扣子智能体。
要做多人卡片：走课堂系统模板或看板。
要在微信里体验：优先 H5 链接，必要时再走小程序模板。
```

3. 修改指令

孩子要会对 WorkBuddy 说：

```text
这个页面哪里看不懂？
按钮要改成什么？
结果缺了什么？
哪句话不像 10 岁孩子会说？
还要少一步还是多一步？
```

## 12 个项目的技术兜底路线

这一段给老师和产品设计用。它的目的不是限制孩子的想法，而是提前判断：哪些项目三天内能稳定做出第一版，哪些只能做演示版，哪些要靠 WorkBuddy agent 调用秒哒、小程序生成工具或其他智能体工具来兜底。

| 项目 | 三天内先做出的第一版 | 默认工具路线 | 可以进阶到什么 | 三天内先别碰 |
|---|---|---|---|---|
| 上学前 3 分钟检查 | 一个“明天要带什么”的出门检查网页，点完显示还差哪几样 | WorkBuddy 生成 H5 / 秒哒网页 | 根据课表自动生成检查项 | 读取班级群消息、自动识别真实课表 |
| 水杯一天还是满的 | 一个喝水打卡页，早读后、体育后、午饭后各点一次 | H5 打卡页 / 微信里打开的 H5 | 家长端看到一天记录 | 真实智能水杯硬件、自动测水量 |
| 零花钱一下就没了 | 一个“买之前想一想”的选择页：目标、余额、这次花多少、还差多少 | H5 小计算器 / 秒哒网页 | 每周消费卡片和目标进度条 | 真实支付、银行卡、复杂记账 |
| 长应用题第一步 | 输入题目，AI 只帮孩子找“已知条件、问题、第一步”，不直接给答案 | WorkBuddy + 扣子智能体 | 拍题后识别文字，再拆第一步 | 自动批改全套作业、直接给最终答案 |
| 错题到底错在哪里 | 一张错因卡：看错题、算错、单位错、第一步错，孩子自己选 | H5 卡片页 + AI 改写提醒 | 拍错题后生成错因候选 | 完整 OCR 题库、长期学习画像 |
| 英语开口不只背稿 | 一个英语追问陪练：先问简单问题，再追问一次真实想法 | 扣子智能体 / WorkBuddy 对话 | 语音输入和语音回复 | 高精度口语评分、发音打分系统 |
| 作文第一句话 | 孩子说一段经历，AI 给 3 个不同开头，孩子选一个继续改 | WorkBuddy / 扣子智能体 | 变成作文开头工作台 | 代写整篇作文 |
| 我想做一个小游戏 | 一张游戏规则卡：角色、操作、得分、失败条件，再生成可试玩 H5 小游戏 | WorkBuddy + 秒哒网页 / H5 游戏模板 | 关卡选择、角色皮肤、排行榜演示 | 多人联网、真实账号、复杂物理引擎 |
| 我的作文想变成漫画 | 一张作文分镜卡：从作文里选 4 个画面，写人物动作、对白和旁白 | WorkBuddy + 图像生成 / H5 漫画页 | 生成 4 格漫画图、翻页小作品、配音展示 | 代写整篇作文、长篇连载、复杂角色一致性 |
| 我想学一个小本领 | 一个同伴小课卡片墙：我想学、谁会教、什么时候有空 | H5 卡片墙 / 秒哒网页 | 微信 H5 预约小课 | 开放陌生人社交、真实收费 |
| 闲置文具想换出去 | 一个闲置交换卡片墙：我有、我想换、谁想要 | H5 卡片墙 / 课堂系统模板 | 微信 H5 小集市 | 真实支付、贵重物品交易 |
| 想要一张专属小作品 | 一个作品点单页：名字、图案、颜色、交付时间、交换物 | H5 表单 + 卡片墙 / 秒哒网页 | 作品小店原型 | 真实接单收款、复杂版权问题 |

### 工具选择的课堂说法

给孩子讲时不要说“技术架构”。可以说：

```text
我们先做一个别人能打开试用的第一版。
如果第一版是记录、按钮、卡片，就先做网页。
如果第一版需要 AI 和人聊天，就先做智能体。
如果它必须在微信里用，就先做微信能打开的网页。
如果时间够，老师再带 WorkBuddy 去试试小程序工具。
```

### 还缺的课堂兜底材料

为了让孩子真的能做到“语音提需求，WorkBuddy 出产出”，后续还要补 4 个材料：

1. `一句话产品需求`模板。
2. `WorkBuddy 生成网页`真实演示提示词。
3. `WorkBuddy 调用秒哒 / 扣子 / 小程序工具`的教师端操作示范。
4. `看第一版怎么提修改意见`的课堂练习。

# 赛道一：生活帮手

生活帮手不做“万能生活管家”。这一赛道要覆盖孩子每天生活里的不同麻烦：出门准备、身体习惯、零花钱选择。三个项目不能都变成“做清单”，否则赛道看起来就很窄。

## 项目 1：上学前 3 分钟检查

### 孩子可见故事

早上 7:18，安安已经穿好鞋，书包也背上了。

妈妈站在门口问：“水杯呢？校卡呢？今天是不是还有美术材料？”

安安一下愣住。水杯在餐桌上，校卡好像夹在昨天的练习册里，美术材料通知在班级群里，体育跳绳挂在阳台。

每一样东西都不难带，可它们散在不同地方。出门前只剩几分钟，安安越想越乱。

妈妈开始催：“快一点，要迟到了。”

到了校门口，安安才发现校卡没带。她站在旁边等老师登记，队伍从她身边一个个走过去。

这不是偶尔一次。只要第二天有体育、美术、科学、社团，家里早上就容易变成“找东西大战”。

### 需求说清楚

- 想帮的人：早上容易漏带东西的孩子，以及每天早上要催孩子的家长。
- 高频场景：上学日前一晚和早上出门前，尤其是有美术、体育、科学、社团的日子。
- 真实痛点：孩子不是不想带，是信息散在课表、作业本、班级群、家长提醒里，早上脑子装不下。
- 现在办法：靠妈妈提醒、自己记、临时翻书包、贴纸条。
- 现在办法的问题：靠人记，容易漏；越催越乱；一漏带就影响当天课堂。

### 价值交换线索

- 孩子愿意每天用，因为少被催、少丢脸。
- 家长可能愿意付费，因为早上少吵一次、少迟到一次。
- 老师可能愿意推荐，因为学生少忘带课堂材料。

### 孩子下一步要问

- 你早上最常漏带什么？
- 是谁最先发现漏带了？
- 你现在靠什么提醒自己？
- 如果有一个工具只帮你检查出门前 3 分钟，你希望它先检查哪 3 样？

## 项目 2：水杯一天还是满的

### 孩子可见故事

下午放学，晴晴把水杯从书包侧袋拿出来。

妈妈一拧开，水几乎还是满的。

“你今天又没怎么喝水？”妈妈问。

晴晴不是故意不喝。早读时水杯在书包里，体育课她忘了拿，午饭后忙着和同学聊天，下午上课又不好意思一直举手去接水。

到了最后一节课，她嘴巴有点干，头也有点沉。可那时候再喝很多水，放学路上又想上厕所。

这件事几乎每天都会发生。很多孩子带了水杯，却不知道一天里什么时候该喝一点，也不知道自己今天到底喝了多少。

家长每天问，孩子每天答“忘了”。问多了，两边都烦。

### 需求说清楚

- 想帮的人：带水杯上学但经常喝不够水的孩子，以及每天提醒喝水的家长。
- 高频场景：每天上学日，早读、体育课后、午饭后、下午课间。
- 真实痛点：孩子不是没有水，是想不起来在合适的时间喝；家长只能放学后才发现。
- 现在办法：家长早上提醒、杯子上贴纸条、老师统一提醒。
- 现在办法的问题：提醒发生在错误时间；孩子在学校里还是容易忘；家长不知道白天真实情况。

### 价值交换线索

- 孩子愿意用，因为不用被家长反复问，也能知道自己今天喝够没有。
- 家长可能愿意付费，因为这件事每天都关心，但家长白天看不见。
- 老师可能愿意推荐，如果它不打扰课堂，只在合适时间提醒或记录。

### 孩子下一步要问

- 你一天里最容易忘记喝水的是哪个时间？
- 你是忘了喝，还是懒得拿水杯？
- 爸爸妈妈怎么知道你今天喝得够不够？
- 如果只提醒 3 次，你希望是哪 3 个时间？

## 项目 3：零花钱一下就没了

### 孩子可见故事

周五放学，小航拿到了这个星期的 20 元零花钱。

校门口旁边的小店新到了贴纸包和盲盒橡皮。小航本来想攒钱买一个 39 元的篮球挂件，可同学一说“这个贴纸今天才有”，他就买了一包。

第二天，他又买了饮料和一支花色很好看的笔。

周日晚上，小航打开钱包，只剩 3 元。

妈妈问：“不是说要攒篮球挂件吗？”

小航也有点后悔。他不是完全乱花钱，他只是每次买的时候都觉得“这个也不贵”。可一周过去，钱去了哪里，他自己也说不清。

很多孩子都会遇到这件事：想买一个更想要的东西，但零花钱总是在小东西上慢慢花光。

### 需求说清楚

- 想帮的人：有零花钱、想攒钱但经常花掉的孩子，以及想教孩子做选择的家长。
- 高频场景：每周拿零花钱后，校门口小店、文具店、自动售货机、线上小额消费前。
- 真实痛点：孩子不是不知道钱重要，是每次小额消费都看起来“不算多”，最后目标买不起。
- 现在办法：家长收走钱、口头提醒、孩子凭感觉记。
- 现在办法的问题：收走钱孩子没有练习机会；口头提醒容易变成说教；凭记忆很难看见钱是怎么花掉的。

### 价值交换线索

- 孩子愿意用，因为能更快买到自己真正想要的东西。
- 家长可能愿意付费，因为它在教孩子做消费选择，而不是只靠没收和批评。
- 老师或营地可能愿意使用，因为它能变成金融素养和创业价值交换的练习。

### 孩子下一步要问

- 你最近一次零花钱花在了什么上？
- 有没有一个东西你想攒钱买，但总是攒不到？
- 买小东西前，你会不会想一想“买了它，我离目标还差多少”？
- 如果有一个工具只帮你做“买不买”的小选择，你希望它提醒你什么？

# 赛道二：学习工具

学习工具不讲“提高成绩”这种大话。它先帮孩子解决一个学习动作：开始、复习、表达、检查。

## 项目 4：长应用题第一步

### 孩子可见故事

数学课最后 8 分钟，辰辰翻到最后一题。

题目有 6 行。前面说图书角，中间说借出和还回，最后问“原来有多少本”。

辰辰会乘法，也会减法。可他读到最后一句，又忘了前面说了什么。

旁边同学已经写了两行算式。辰辰越看越急，最后随便写了一个加法。

老师走过来问：“你是不会算吗？”

辰辰摇头：“我是不知道先看哪一句。”

这种事每周都会发生。题不是完全不会，可第一步找不到，后面就全乱了。

### 需求说清楚

- 想帮的人：看到长应用题就发愣的孩子。
- 高频场景：数学练习、单元测验、家庭作业里的应用题。
- 真实痛点：孩子会基础计算，但不会从长文字里找条件和第一步。
- 现在办法：家长讲一遍、老师讲一遍、孩子猜一个算式。
- 现在办法的问题：别人一讲就懂，自己下次还是不会开始。

### 价值交换线索

- 孩子愿意用，因为能开始写，不用空着。
- 家长可能愿意付费，因为辅导应用题最容易吵架。
- 老师可能愿意推荐，因为它不直接给答案，只帮孩子拆题。

### 孩子下一步要问

- 你看到长题时，最先卡在哪里？
- 你是看不懂题意，还是不知道第一步算什么？
- 大人给你讲题时，哪一句最有用？
- 如果工具只帮你找“第一步”，你希望它怎么提示？

## 项目 5：错题到底错在哪里

### 孩子可见故事

期中考试发下来，林林数学错了 9 道题。

妈妈说：“把错题订正一下。”

林林把正确答案抄了一遍。第二天老师讲评，他听懂了。可过了一周，类似的题又错了。

他翻开错题本，里面写着一堆红笔答案，却看不出自己到底错在哪里。

有的是看错单位，有的是漏看“至少”，有的是计算错，有的是第一步就想歪了。

错题本看起来很努力，但没有告诉他下一次怎么避开同一个坑。

### 需求说清楚

- 想帮的人：有错题本，但总是反复错同类题的孩子。
- 高频场景：考试后、作业订正后、单元复习前。
- 真实痛点：孩子订正了答案，但不知道错因，复习时抓不到重点。
- 现在办法：抄正确答案、家长讲、老师讲评、错题本贴一堆。
- 现在办法的问题：记录很多，真正能提醒下一次的东西很少。

### 价值交换线索

- 孩子愿意用，因为复习不用从头看全部题。
- 家长可能愿意付费，因为能看到孩子不是只抄答案。
- 老师可能愿意推荐，因为能帮助学生归类错因。

### 孩子下一步要问

- 你错题本里最多的是哪类错？
- 你订正后，还会不会再错同类题？
- 哪一种提醒最能帮你下次避开？
- 如果只做一张“错因卡”，你想先记录什么？

## 项目 6：英语开口不只背稿

### 孩子可见故事

阿泽准备了一分钟英文介绍。

第一句他背得很熟：“My favorite thing is robots.”

轮到他展示时，前 30 秒都很顺。老师突然问：“Why do you like robots?”

阿泽停住了。

他脑子里有答案：机器人可以帮老人拿东西，也可以去危险的地方。可是英文一出口，只剩下一句：“Because... good.”

下台以后，他有点懊恼：“我不是没想法，是别人一追问我就接不上。”

英语口语练习经常这样。背稿能过第一关，真正对话时就卡住。

### 需求说清楚

- 想帮的人：能背稿，但怕被追问的孩子。
- 高频场景：英语课口语展示、演讲、外教课、英语角。
- 真实痛点：孩子有想法，但不会把想法变成能接住追问的英文表达。
- 现在办法：背固定稿、家长陪练、跟读软件。
- 现在办法的问题：背稿解决不了临场追问；家长不一定会陪练。

### 价值交换线索

- 孩子愿意用，因为开口时不那么慌。
- 家长可能愿意付费，因为口语陪练是持续需求。
- 老师可能愿意推荐，因为它可以让学生从背稿走向对话。

### 孩子下一步要问

- 你说英语时最怕别人问什么？
- 你是不会单词，还是不知道怎么把想法接下去？
- 你希望陪练先问简单问题，还是追问你真实想法？
- 如果只能练一个场景，你最想练哪一个？

# 赛道三：创意工坊

创意工坊不做“帮我生成一个作品”。它先帮孩子从卡住的地方往前走一步，让孩子自己的想法能出来。

## 项目 7：作文第一句话

### 孩子可见故事

语文课要写《一次难忘的活动》。

小朵脑子里有画面：运动会、接力棒、最后一圈、全班喊加油。

她打开文档，写下：“今天，我要写一次难忘的活动。”

她看了一眼，又删掉。

太普通了。

十分钟过去，她脑子里的画面很多，文档第一行还是空白。旁边同学已经写了半页，她开始着急。

她不是没有内容。她是不知道从哪一幕开始。

### 需求说清楚

- 想帮的人：有经历、有画面，但作文开头写不出来的孩子。
- 高频场景：周记、作文课、读后感、活动记录。
- 真实痛点：孩子脑子里有材料，但第一句话太难，开不了头。
- 现在办法：套模板、问家长、上网搜开头。
- 现在办法的问题：模板像别人写的，搜来的开头没有自己的画面。

### 价值交换线索

- 孩子愿意用，因为不用盯着空白页发愁。
- 家长可能愿意付费，因为作文辅导很高频。
- 老师可能愿意推荐，如果它只是帮孩子找到自己的第一幕，而不是代写。

### 孩子下一步要问

- 你写作文最常卡在开头、中间还是结尾？
- 你脑子里有画面时，为什么第一句话还是写不出来？
- 你喜欢从动作、声音、对话还是画面开始？
- 如果工具帮你列 3 个开头，你希望它根据你的哪段经历来写？

## 项目 8：我想做一个小游戏

### 孩子可见故事

周六社团课，小宇想做一个“小猫接星星”的小游戏。

他脑子里已经有画面：小猫左右移动，天上掉星星，接到一颗加 1 分，碰到乌云就扣分。

小宇打开 WorkBuddy，说：“帮我做一个好玩的游戏。”

出来的页面确实能动，可里面没有小猫，也没有星星。一个方块在屏幕上跳来跳去，同学看了半天问：“我要干嘛？”

小宇有点急：“我明明想得很清楚啊。”

其实他没有说清楚：玩家控制谁？用什么键？接到什么得分？碰到什么会输？

### 需求说清楚

- 想帮的人：脑子里有游戏想法，但不知道怎么说清规则的孩子。
- 高频场景：AI 课、编程课、社团课、营地作品制作、课后想做小游戏。
- 真实痛点：孩子脑子里有画面，但说给 AI 或同学听时，只说“做个好玩的游戏”，结果做出来和想象不一样。
- 现在办法：反复让 AI 改，或者放弃。
- 现在办法的问题：没有先说清角色、操作、得分和失败条件，改很多次也容易跑偏。

### 价值交换线索

- 孩子愿意用，因为自己的游戏能真的打开给同学玩。
- 家长可能愿意付费，因为孩子能从“玩游戏”走向“设计游戏”。
- 营地和社团老师可能愿意使用，因为它能把创意变成可试玩的作品。

### 孩子下一步要问

- 你想做什么小游戏？
- 玩家控制谁？
- 怎么得分，怎么失败？
- 如果第一版只做 1 分钟试玩，你最想保留哪一个玩法？

## 项目 9：我的作文想变成漫画

### 孩子可见故事

周五语文课，小雨写完了一篇《难忘的运动会》。

她写了满满一页：枪声一响，她冲了出去，同学们在旁边加油，最后她跑到了终点。

可她读给同桌听，同桌只记住一句：“你参加了跑步比赛。”

小雨有点着急。她明明记得很多画面：起跑前手心出汗，跑到一半鞋带松了，旁边同学喊她的名字，最后她咬牙冲过终点。

这些画面都在作文里，可读起来像一大段文字，别人一下看不见最精彩的地方。

小雨真正卡住的是：怎么从自己的作文里挑出 4 个关键画面，变成大家一眼看懂的漫画？

### 需求说清楚

- 想帮的人：写完作文、日记、游记或故事后，想让别人更愿意看的孩子。
- 高频场景：语文作文、周记、研学游记、读书分享、社团故事、营地作品展示。
- 真实痛点：孩子写完了一大段文字，但不知道哪几幕最精彩，也不知道漫画每一格该画什么。
- 现在办法：直接交作文，或者只让 AI 画一张图。
- 现在办法的问题：直接交作文不一定有吸引力；只画一张图讲不出前后变化；如果不先拆分镜，AI 很容易画偏。

### 价值交换线索

- 孩子愿意用，因为自己的作文能变成可以给同学看的漫画小作品。
- 家长可能愿意付费，因为它能让孩子愿意重读和修改自己的作文，而不是让 AI 代写。
- 老师可能愿意推荐，因为它能帮助孩子看见“开场、麻烦、转折、结果”这些写作结构。

### 孩子下一步要问

- 你的作文里最像电影的一幕是哪一句？
- 这件事一开始发生在哪里？
- 中间出了什么小麻烦？
- 后来发生了什么转折？
- 最后一格想让别人记住什么？

# 赛道四：校园社区

校园社区先别从“老师怎么省心”开始。它先看孩子之间真实会发生的小交换：我想学一个本领、我想换一个东西、我想请同学做一个小作品。这里的价值交换更直接，孩子可能愿意付出星星币、自己的闲置物、一次帮忙，或者认真给出需求。

## 项目 10：我想学一个小本领

### 孩子可见故事

课间十分钟，沐沐看见隔壁桌的同学把魔方转得飞快。

她也想学。可是下节课快开始了，她只来得及问一句：“你能教我吗？”

对方说：“可以啊，不过我今天中午要排练。”

午饭后，沐沐又忘了去找他。第二天，她看到另一个同学在教别人画立体字，才发现班里其实有很多人会小本领：魔方、折纸、投篮、手账、画头像。

可想学的人不知道谁会，愿意教的人也不知道谁想学。

### 需求说清楚

- 想帮的人：想学一个小本领的孩子，以及愿意教别人 10 分钟的孩子。
- 高频场景：课间、午休、社团前后、营地自由活动时间。
- 真实痛点：会的人和想学的人互相看不见，临时问又经常时间不合适。
- 现在办法：看到谁会就当场问，或者只找熟人。
- 现在办法的问题：容易错过；不会主动问的孩子就学不到；会教的孩子也不知道谁真的想学。

### 价值交换线索

- 想学的孩子愿意付出星星币、贴纸，或者帮对方做一件小事。
- 会教的孩子愿意被看见，因为自己的本领变得有用。
- 社团老师可能愿意使用，因为它能让孩子互相教、互相学。

### 孩子下一步要问

- 你最近想学哪个小本领？
- 班里谁会这个本领？
- 如果请同学教你 10 分钟，你愿意拿什么来换？
- 会教的人最想先知道什么：时间、难度，还是对方想学到哪一步？

## 项目 11：闲置文具想换出去

### 孩子可见故事

周五整理书包时，阿泽从抽屉里翻出三盒彩色贴纸、两支重复的荧光笔，还有一本看完的漫画。

这些东西他不常用了，可又舍不得扔。

同桌小北正好想找荧光笔，另一个同学想要贴纸做手账。可阿泽不知道谁需要，别人也不知道他愿意换。

课间他拿着贴纸问了一圈，有人想换，但没有带东西；有人有橡皮章，却已经走远了。

一上午过去，贴纸还在阿泽手里，想要贴纸的人也没换到。

### 需求说清楚

- 想帮的人：有闲置文具、贴纸、书本的孩子，以及正好想要这些东西的孩子。
- 高频场景：整理书包、换新文具、活动前做手账或海报、班级跳蚤市场前。
- 真实痛点：东西不贵，但扔了可惜；想换的人互相不知道对方手里有什么。
- 现在办法：课间拿着东西问一圈，或者等跳蚤市场。
- 现在办法的问题：时间不对、对象不对、想换什么说不清，很容易换不成。

### 价值交换线索

- 孩子愿意用闲置物、星星币或一次帮忙来交换。
- 家长可能支持，因为孩子学会珍惜物品，也学会表达自己想要什么。
- 营地或班级可以把它变成安全的小集市练习。

### 孩子下一步要问

- 你抽屉里有什么东西用不上了？
- 你最近想换到什么？
- 你愿意拿什么来换：星星币、旧物，还是帮对方做一件事？
- 交换前要说清哪些信息，才不容易后悔？

## 项目 12：想要一张专属小作品

### 孩子可见故事

班级要办读书分享会，然然想给自己的书桌放一张小桌牌。

她想要的不是普通打印字，而是一张有小狐狸、星星和自己名字的手绘桌牌。

她知道同班的小禾画画很好，就跑去问：“你能帮我画一张吗？”

小禾问：“你想要多大？写什么字？要什么颜色？什么时候要？”

然然一下答不上来。她只说“可爱一点”，小禾也不知道该怎么画。

第二天，小禾画了一张蓝色小猫桌牌，然然却想要橙色小狐狸。两个人都有点尴尬。

### 需求说清楚

- 想帮的人：想要专属小作品的孩子，以及愿意接小单、做小作品的孩子。
- 高频场景：读书分享、生日贺卡、社团名牌、头像、书签、桌牌、作品展示。
- 真实痛点：想要的人说不清要求，会做的人不知道怎么接单，也不知道值不值得花时间做。
- 现在办法：直接找会画的人说一句“帮我画一个”。
- 现在办法的问题：尺寸、颜色、文字、交付时间、交换方式都没说清，最后容易做偏。

### 价值交换线索

- 想要作品的孩子愿意用星星币、贴纸、零食券或一次帮忙来换。
- 会做作品的孩子愿意接单，因为自己的手艺被看见，还能练习服务别人。
- 老师或家长可能愿意支持，因为这是很直观的需求表达和价值交换练习。

### 孩子下一步要问

- 你想点单什么小作品？
- 你希望它长什么样：图案、颜色、名字、大小？
- 你什么时候要用？
- 你愿意拿什么来换这件作品？

# 建议放进 PPT 前的改法

当前 PPT 如果继续用“三个项目卡片”呈现，建议每张卡不要只写故事片段。每张项目卡至少要出现 4 个孩子能读懂的锚点：

1. 经常发生：每天 / 每周 / 每次活动前。
2. 谁真的想要：孩子、家长、老师、同学。
3. 现在怎么凑合：靠记、靠催、到处问、临时找人。
4. 值得交换什么：星星币、闲置物、一次帮忙、认真使用、推荐给同学。

孩子可见版本可以写成：

```text
这件事经常发生吗？
谁真的想要？
现在大家怎么凑合？
如果解决了，别人愿意拿什么来换？
```

老师讲解时再补一句：

```text
创业不是先想一个很大的产品，而是先找到一个经常发生、真的让人烦、现在办法又不够好的麻烦。
```

# 本版自检

- 10 岁能懂：故事场景来自上学、放学、作业、创作、班级活动。
- 高频感：每个项目都标了每天、每周、考试后、活动前等重复场景。
- 痛点感：每个项目都写了现有办法为什么不够好。
- 价值交换：每个项目都写了谁可能愿意付出星星币、时间、闲置物、一次帮忙，或者真实使用和推荐。
- 解决方案：没有直接替孩子设计最终产品，只留下问题边界和下一步采访问题。
